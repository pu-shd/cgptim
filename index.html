    How it works & privacy
    1. In ChatGPT, request a data export from Settings → Data controls → Export data. Download the ZIP from the email.
    2. Open that ZIP here, or select its conversations.json together with any related JSON files.
    3. Choose a conversation and branch. Use the checkboxes or a message range to choose the context you want.
    4. Review the download, attach it to a new chat, and paste the continuation prompt. Attach original media separately if needed.

    All processing happens locally. No analytics, external fonts, API calls, or browser storage. Reloading or clearing the archive removes it from this app’s memory. Downloads remain on your device. Markdown images and embedded HTML media are blocked. Links open only when you click them.

    Use a trusted copy of this app and review exports before sharing. A transcript can contain instructions and private information. Unknown content types are labeled; no automatic summary is invented.
